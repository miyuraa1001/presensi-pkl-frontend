Langkah Konfigurasi Backend:

  1. Buka Google Spreadsheet Baru dengan 4 tab: Master_PKL, Log_Presensi, Log_Perizinan, Rekap_Bulanan.
  2. Buka Google Drive dan buat 2 folder: Folder Foto Presensi dan Folder Bukti Izin.
  3. Buka menu Extensions > Apps Script pada Google Spreadsheet Anda.
  4. Salin seluruh isi file Code.gs yang ada di root repo ini.
  5. Isi ID Spreadsheet dan ID Folder Google Drive di baris 21-23 file Code.gs.
  6. Klik tombol Deploy > New deployment, pilih tipe Web app. Atur Execute as: Me dan Who has access: Anyone.
  7. Salin URL Web App yang dihasilkan ke input URL di tab Pengaturan!
