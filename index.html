Panduan Integrasi Google Apps Script

File Code.gs sudah tersedia di root direktori project!

Langkah Konfigurasi Backend:

  1. Buka Google Drive dan buat 3 Folder:
    • Foto_Presensi_PKL (untuk nampung foto absensi & watermark IN/OUT)
    • Foto_Profil_PKL (untuk nampung foto profil peserta magang)
    • Dokumen_SKD_PKL (untuk nampung berkas/foto surat sakit & Surat Keterangan Dokter)

    Tip: Anda juga bisa menjalankan fungsi createDriveFoldersAutomated di Code.gs untuk membuat ketiga folder ini otomatis!

  2. Buka Google Spreadsheet Baru.
  3. Buka menu Extensions > Apps Script pada Spreadsheet Anda.
  4. Salin seluruh isi file Code.gs dari root repo ini ke editor Apps Script.
  5. Isi SPREADSHEET_ID, FOLDER_PRESENSI_ID, FOLDER_PROFIL_ID, dan FOLDER_SKD_ID di baris 28-31 file Code.gs.
  6. Auto-Generate Database: Pilih fungsi setupDatabaseSheets di toolbar atas lalu klik Run (Jalankan). Seluruh sheet & kolom akan dibuat otomatis!
  7. Klik menu Deploy > New deployment, pilih tipe Web app. Atur Execute as: Me dan Who has access: Anyone.
  8. Salin URL Web App yang dihasilkan ke input URL di tab Pengaturan aplikasi atau ke Vercel!

Cara Pasang Environment Variables di Vercel Dashboard:

  1. Buka dashboard project Vercel Anda di vercel.com.
  2. Pilih tab Settings > pilih menu Environment Variables di sisi kiri.
  3. Tambahkan 2 variabel rahasia berikut:
    • Key: GAS_URL
      Value: URL Web App Google Apps Script Anda (akhiran /exec)
    • Key: GAS_SECRET_CODE
      Value: DAIHATSU_PKL_SEC_2026 (wajib sama dengan di Code.gs)
  4. Pastikan variabel API_SECRET_TOKEN di baris 35 file Code.gs nilainya sama persis!
  5. Klik Save lalu Redeploy project di Vercel. Selesai! Sistem akan otomatis terlindungi Secret Code tanpa kendala CORS.

A
Cara Pasang WebAPK di HP Android (Tanpa Logo Chrome)
  1. Hapus icon lama: Jika sebelumnya sudah ada icon dengan badge Chrome kecil di layar utama, hapus/uninstall terlebih dahulu.
  2. Klik tombol hijau "Pasang" di atas atau tombol pada kartu Pengaturan.
  3. Jika menggunakan menu browser titik tiga (⋮) di Chrome, pastikan memilih opsi "Instal Aplikasi" (bukan "Tambahkan pintasan").
  4. Konfirmasi "Instal" pada pop-up resmi Google Play Services.
  5. Aplikasi Presensi PKL akan otomatis terpasang dengan icon resmi Astra Daihatsu beresolusi tinggi tanpa ada logo Chrome, persis seperti aplikasi Stockyard!
iOS
Cara di iPhone / iPad (Safari)
  1. Buka halaman web ini di browser bawaan Safari (bukan browser di dalam WA/IG).
  2. Tap ikon Share / Bagikan (kotak dengan panah ke atas) di bar navigasi bawah Safari.
  3. Scroll ke bawah pada menu yang muncul, lalu pilih "Tambah ke Layar Utama" (Add to Home Screen ).
  4. Tap tombol "Tambah" di pojok kanan atas layar. Selesai! Icon aplikasi presensi akan muncul di Home Screen iPhone Anda.

Keuntungan Memasang ke Layar Utama:

  • Membuka presensi 1-tap langsung tanpa perlu repot mengetik link web lagi.
  • Layar penuh (full-screen) tanpa address bar browser yang mengganggu.
  • Akses lokasi GPS bengkel & kamera presensi berjalan lebih cepat dan presisi.
